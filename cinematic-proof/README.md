# BEHIND DEL MUNDO — cinematic proof

Isolated Remotion experiment. It does not replace or modify the existing daily production pipeline.

- 18 seconds, 1080×1920, 30 fps.
- Real high-resolution Wikimedia Commons photographs, with reusable licences checked and credits recorded.
- Animated camera moves, editorial typography, animated mechanical overlays, transitions and film grain.
- Spanish (Spain) narration and an original synthetic atmospheric sound bed are added by the CI workflow.
- Rendered MP4 and image/contact-sheet evidence are uploaded as a GitHub Actions artifact.

The first proof uses the Antikythera mechanism story as a test case. It is intentionally a complete short sequence, not a new daily publishing job.
